The POUR Principles:
Understanding Web Accessibility

Sort common web accessibility practices into the four POUR principles.

POUR Categories

Perceivable

Information and interface elements must be presented in ways users can perceive, regardless of their sensory abilities.

Operable

Interface components and navigation must be usable by everyone, including people who rely on a keyboard or other input methods.

Understandable

Information and interface behavior must be clear, predictable, and easy to understand.

Robust

Content must work reliably with different browsers, devices, and assistive technologies.

Accessibility Practices

POUR principles are part of the Web Content Accessibility Guidelines (WCAG).
