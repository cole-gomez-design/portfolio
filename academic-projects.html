Academic Projects

This page showcases projects developed through my coursework in the University of Florida Educational Technology Program. From web design and interactive learning activities to multimedia development and AI-assisted design, these projects demonstrate my technical skills, creative process, and approach to solving problems through digital tools and technology.

EME6208: Designing Integrated Media Environments I

Crafting Visuals

This project explored traditional and AI-assisted graphic design through the creation of a personal logo and two book covers.

I designed a vector logo in Adobe Illustrator and created a traditional photo-composite book cover in Photoshop, then used Adobe Firefly to generate an alternative cover for comparison.

Web Accessibility Quiz

An interactive quiz introducing key concepts in website accessibility, including accessibility standards and practices for creating more inclusive digital experiences.

I designed and developed the quiz using HTML, CSS, and JavaScript as part of my educational technology coursework. The project demonstrates accessible web design and interactive learning development.

POUR Drag-and-Drop Activity

An interactive learning activity that introduces the four principles of web accessibility: Perceivable, Operable, Understandable, and Robust (POUR).

I designed and developed the activity using HTML, CSS, and JavaScript as part of my educational technology coursework, creating an interactive way for learners to practice identifying accessibility principles.

E-Portfolio Template

This project involved creating a personal e-portfolio using HTML and an external CSS stylesheet to showcase professional experience, education, and project work.

I redesigned the original template with a custom color palette, typography, navigation, and responsive layout, while incorporating accessibility features. I also generated alternative versions using ChatGPT and Claude.

View the E-Portfolio Project Page

Educational Video

This project focused on producing an instructional video about identifying green and loggerhead sea turtles by their nesting tracks.

I developed the script, selected and edited images, recorded narration, and assembled the video in Clipchamp with captions, transitions, and music. I also created an AI-generated version using Artlist.

Digital Animation

This project involved creating a short AI-generated animation explaining the science of visual attention through visual elements and movement.

I developed and refined the generation prompts, then edited the animation in Clipchamp to add narration, music, a title card, and additional visual adjustments.

Screencast

This project involved creating a narrated screencast demonstrating a how to make a composite image using layer masks in Adobe Photoshop.

I recorded teh screencast using windows snipping tool, recorded the narration in Audacity, and then added them to Clipchamp for editing and final production. Final production included adding a title card, transitions, background music, and visual pointers to highlight the layer mask process.
